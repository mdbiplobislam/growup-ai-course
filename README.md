৫০ দিনের কোর্স নোট অ্যাপ। **ট্রেইনার:** Md Biplob — NSDA CBT&A সার্টিফায়েড ট্রেইনার ও অ্যাসেসর।

লাইভ: _(GitHub Pages চালু করার পর এখানে লিংক বসবে)_

## কাঠামো

```
index.html            অ্যাপের খোলস — কোনো কন্টেন্ট নেই (~1 KB)
assets/app.css        অ্যাপের স্টাইল
assets/blocks.css     মাস্টারক্লাস ব্লকের স্টাইল
assets/app.js         নেভিগেশন ও চাহিদামতো দিন লোড করা
assets/blocks.js      কুইজ, ভিডিও, আউটকাম চেকলিস্টের কাজ
assets/cms.js         এডিট মোড (ব্রাউজারে, localStorage-এ সংরক্ষিত)
data/nav.json         সাইডবার, সূচিপত্র ও ৫০ দিনের শিরোনাম
data/days/NN.json     এক দিনের মার্কডাউন ও পাতার গঠন
data/ins/NN.json      এক দিনের মাস্টারক্লাস ব্লক
tools/add_day.py      নতুন দিন বসানোর কমান্ড
tools/blocks.py       ব্লক হেল্পার (২২টি)
```

**মূল নীতি:** অ্যাপ আর কন্টেন্ট আলাদা। শিক্ষার্থী যে দিনটা খোলেন শুধু সেটাই ডাউনলোড হয় (~৩০–১৮০ KB),
পুরো ১.৬ MB নয়।

## একটা দিন যোগ বা হালনাগাদ করা

```bash
python tools/add_day.py --day 24 --blocks blocks24r.json
git add -A && git commit -m "Day 24 — Pixlr" && git push
```

ব্যস। কোনো ব্রাউজার নেই, কোনো এডিটরে পেস্ট করা নেই।

## কিছু ভেঙে গেলে

```bash
git log --oneline          # কোন কমিটে কী হয়েছে
git revert <commit>        # ওই পরিবর্তনটা ফিরিয়ে নিন
```

প্রতিটা পরিবর্তন আলাদা কমিট, তাই একটা দিন নষ্ট হলে বাকি ৪৯টা অক্ষত থাকে।

## স্থানীয়ভাবে চালানো

`file://` থেকে চলবে না (fetch ব্লক হয়)। একটা সার্ভার লাগবে:

```bash
python3 -m http.server 8000
# তারপর http://localhost:8000
```

## GitHub Pages চালু করা

Settings → Pages → Source: `main` branch, folder `/ (root)` → Save।
এক মিনিটের মধ্যে `https://<username>.github.io/<repo>/` লিংকটা কাজ করবে।

## কন্টেন্টের অপরিবর্তনীয় নিয়ম

1. **শুধু যাচাইকৃত তথ্য** — ট্রেইনার সম্পর্কে কোনো কল্পিত ক্লায়েন্ট, সংখ্যা বা কেস স্টাডি নয়।
2. **টাকার অঙ্ক নয়, সূত্র** — রেট = মাসিক লক্ষ্য ÷ কাজের ঘণ্টা; দাম = রেট × ঘণ্টা × ১.৩।
3. **আইনি পরামর্শ নয়** — আইন-সংক্রান্ত প্রতিটি ব্লকে স্পষ্ট ডিসক্লেইমার।
4. **ভিডিও শুধু oEmbed দিয়ে যাচাই করা** হলে তবেই বসবে।
